# AI 督学 Agent · 可运行 Demo

教育行业私域转化场景的 AI 运营 Agent。**不是聊天机器人，是受约束的 Agent**：
状态机驱动 + 意图路由 + 确定性风控，模型只介入「意图识别」和「话术生成」两个点。

---

## 一、怎么跑（30 秒）

```bash
cd "运营督学agent demo"

# 方式一：命令行，一条命令跑完 11 个场景，直接看决策过程（零依赖）
python3 cli.py

# 方式二：三栏工作台 UI
pip install streamlit pandas
streamlit run app.py

# 方式三：交互式，自己输入学员说的话
python3 cli.py -i

# 方式四：离线评估，30 条金标样本出一份指标报告
python3 eval/run_eval.py
```

**不需要 API Key 也能跑。** 未配置时自动进入 MOCK 模式：意图用关键词规则、话术用模板填充。
整个七层流程、风控、熔断、留痕全部真实运行——这些才是 demo 要展示的东西。

接真模型（可选）：

```bash
export LLM_API_KEY=sk-xxxx
export LLM_BASE_URL=https://api.deepseek.com/v1   # 或 dashscope、moonshot 等 OpenAI 兼容地址
export LLM_MODEL=deepseek-chat
python3 cli.py
```

配了 key 之后：意图分类走模型（temperature=0），中/高自由度话术走模型润色，低自由度仍然走模板
——**这个分级本身就是产品设计，别改。**

## 二、架构：七层

```
输入（定时事件 / 学员消息）
  ↓
① 闸门 gate        不进模型就挡掉：高危词、触达超限、已归档
  ↓
② 上下文装配         Stage + 学员档案 + 已上课程 + 触达次数
  ↓
③ 意图识别 router    小模型 / temp=0 / 强制 JSON，输出 {意图, 置信度, 情绪}
  ↓
④ 策略决策 policy   ★核心：策略 = f(Stage, 意图, 情绪, 置信度, 触达次数)
  ↓
⑤ 执行 executor     要事实→检索 / 要动作→工具 / 要说话→按自由度生成
  ↓
⑥ 风控闸门 guard    所有输出必经：禁语、报价、静默时段、长度
  ↓
⑦ 留痕 + 状态回写    trace.jsonl 可回溯、Stage 推进、触达计数
```

**关键设计：路由键是 `(Stage, 意图)` 复合键，不是单独的意图。**
同一句"有点贵"，D2 是"把注意力拉回课程价值"，D5 是"强制转人工"。

运行 `cli.py` 你会看到 `李婷 D1` 和 `刘洋 D5` 面对不同消息时，AI 权限的差异。

## 四、改成你自己的业务（这才是真正的工作量）

代码不用改。**改这 4 个 JSON 就行**——这正是「策略配置化」的产品设计：

| 你要改什么 | 改哪个文件 | 大概要多久 |
|---|---|---|
| 学员档案（换成真实结构） | `data/students.json` | 1 小时 |
| 话术卡片（用你们真实话术） | `data/cards.json` | **2–3 天，最花时间** |
| 课程/价格/师资事实 | `data/knowledge.json` | 2 小时 |
| 禁语与频控规则 | `data/forbidden.json` | 半天 |
| 策略组合（谁自动、谁人工） | `agent/policy.py` 的 MATRIX | 1 天，要先拉真实对话 |

**你的时间应该 90% 花在 cards.json 上，不是写代码。**
一张好卡片 = 目标（这一句要让学员做什么动作）+ 骨架 + 可变量 + 禁语。
别写"表达关心"，要写"让学员点开链接"。

## 五、已经内置的产品判断（面试就用这些讲）

1. **受约束的 Agent，不是自主 Agent。** 模型只在两个点介入，其余全是确定性规则。私域场景一次错误报价就是合规事故，容错率不允许模型自由发挥。
2. **人机边界是算出来的，不是拍的。** 结论是"钱和情绪必须人接，信息和流程AI全自动"。
3. **负面情绪自动升档。** `AUTO` 遇负面情绪降级为 `CONFIRM`。
4. **Stage 权限封顶。** D4/D5 不允许出现高自由度生成。
5. **没有对应话术卡片就不许说话。** 未定义场景直接转人工，不允许即兴发挥。
6. **低置信度闭嘴。** 置信度 < 0.75 进人工队列，宁可不动不可乱动。
7. **主动推送有频控、学员主动说话不算打扰。** 这个区分很重要，做错会误伤真实互动。
8. **风控在出口而不是入口。** 所有对外文案必须过禁语/报价/时段/长度四道检查。
9. **全链路留痕。** 每条消息能回溯当时喂了什么上下文、命中哪张卡片、哪道闸门放的行。

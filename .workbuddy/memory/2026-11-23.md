工作区：`E:/onedrive/26919newcode/运营督学agent demo`（Python，零第三方依赖，Streamlit 为可选 UI）

### 项目定性
教育私域转化的「受约束 Agent」demo，不是聊天机器人。七层流水线：gate → 上下文装配 → router(意图) → policy(策略) → executor → guard(风控) → trace/回写。核心是 `policy.MATRIX`，路由键为 `(Stage, 意图)` 复合键；模型只在意图识别（temp=0，强制 JSON）和话术润色（mid/high 自由度）两处介入。业务链路：5 天插画体验课 → D1–D5 阶段推进 → 进阶班订金/尾款。

### 已修复的 7 处缺陷（全部验证通过）
1. **状态回写是假的** → 新增 `agent/store.py`（进程内可变状态，`get()` 返副本、显式 `commit()`），pipeline 第 7 层真实回写 stage / touch_count（仅 timer 计数）/ last_reply_hours。原来 `students.json` 只读加载，Stage 永远不变。
2. **LLM 强制 JSON 污染话术** → `LLM.chat(json_mode=False)` 默认纯文本，只有 `router.classify` 传 True；`except` 不再恒返回 None，改记 `last_error`。
3. **意图集合缺 2 项** → `INTENTS` 补「转化铺垫」「尾款提醒」至 11 类，RULES 顺序放在「价格咨询」之后，保证"进阶班多少钱"仍判价格咨询走人工。D4-01 / D5-01 卡片从不可达变为可达。
4. **静默时段误伤回复** → `guard.check(is_reply=)` 返回三元组，学员主动消息在静默时段不拦截，AUTO 降级为 CONFIRM 草稿。
5. **金额正则过宽** → 删除裸 `\d{3,}`，改为货币后缀 / 价格词前缀上下文匹配。"365天""90分钟""19:30""24:00" 均放行，"3980 元""打折" 仍拦。
6. **频控双写** → policy 删硬编码 3，改读 `forbidden.json.max_touch_per_day`。
7. **D5 归档判据错** → `Student` 新增 `paid_final`，`advance()` 用尾款而非订金判 DONE（原逻辑会让还在问尾款的学员被归档）。

附带：pipeline 的 HUMAN/STOP 分支补写 `blocked`，评估看板"被拦截次数"不再漏计策略层转人工；cmd 演示新增 D4 报名、D5 尾款两场景；`show()` 增加「状态回写」行。

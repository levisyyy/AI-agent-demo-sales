## 为 AI 督学 Agent 搭建离线评估框架（简历项目关键一环）

### 背景
用户以此项目为简历代表作，缺"度量"。目标：把"感觉好一点"变成可归因的数字。

### 交付物 `eval/`
- `run_eval.py` 回放入口：每条样本前 `store.reset()` 保证独立，时间固定 19:30 避开静默时段
- `dataset.py` 金标集加载 + 严格校验（缺字段 / mode 非法 / 意图名拼错 均直接报错，已实测）
- `metrics.py` 五类指标 + 混淆矩阵 + 纯标准库终端表格（中文按 2 格对齐）
- `attribute.py` 按「因果链上第一个偏离金标的层」归因
- `make_template.py` 从 `raw_messages.txt` 生成待标注骨架
- `cases/gold.jsonl` 30 条人工标注（覆盖 D1–D5、四档权限、gate 拦截、低置信度）
- `reports/` 输出 md 报告 + csv 明细；`TRACE_PATH` 环境变量隔离评估留痕（改 `agent/trace.py`）

### 指标口径（关键设计，勿改）
- **动作准确率**是产品指标；**意图准确率**是技术指标。二者必须分开：意图错但动作对（E028）业务无害。
- **漏放率**（该人接却被自动处理）优先级最高，是事故级。
- 误拦率 / 保守率 分开统计：前者白干人工，后者白吃人力。

### 归因规则（踩过的坑）
初版把闸门"正拦"（gold=HUMAN 且确实拦了）也算成失败，导致归因虚高 3 条。
修正：**动作判对即不归因**，只对 `pred_mode != gold_mode` 的样本定位。

### 故意埋的 3 条缺陷（已全部被正确抓到）
| 样本 | 现象 | 真实缺陷 |
|---|---|---|
| E022 D5"名额还有吗" | CONFIRM→HUMAN，归因④策略决策 | `MATRIX` 缺 `(D5, 转化铺垫)` |
| E025 D2 触达 3 次仍推提醒 | STOP→HUMAN，归因①闸门 | `gate` 一律返回 HUMAN，"不打扰"应是 STOP |
| E028"这个能分期吗" | 动作对、意图错 | 关键词规则识别不到"分期"，应属价格咨询 |

### 当前基线（MOCK 模式）
30 条：动作 28/30 93.3%、意图 26/27 96.3%、误拦 1/19 5.3%、漏放 0/11、保守 0/9。
**MOCK 数字只能证明规则与流程，接真模型后必须同集重跑并分开报。**

### 下一步
扩样本到 200 → 按归因分布决定下一周修哪层；接真模型重跑形成两份对比数字。

## 数据层换 SQLite + 工作台可视化编辑（2026-11-24 深夜）

### 方案
- `agent/db.py`：SQLite 单文件 `data/agent.db`（标准库 sqlite3，零安装）。4 张表：
  students（数组字段存 JSON 字符串）、cards（复合键拆 stage/intent/emotion 三列）、
  knowledge（嵌套拍平成 section/k/v 行，topics_D1 格式）、forbidden_words + settings。
- 首次建库自动从 4 个 JSON 导入 seed（`.seeded` 标志防重灌）；JSON 之后只读。
  `reseed()` 全量重灌、`reseed_students()` 只重灌学员。
- `load_*` 返回与原 JSON **完全同构**的结构 → gate/guard/executor/policy 只改数据源不改逻辑。
- store.py：内存为工作副本、DB 为持久层；commit 双写；reset 从 DB 重读（评估样本隔离仍有效）。
- 改踩坑：knowledge.json/cards.json 顶层都有 `_meta` 字符串键，seed 时要跳过。

### 工作台「数据管理」tab
学员/卡片/禁语用 `st.data_editor` 可视化编辑（数组字段逗号分隔、bool 用 checkbox），
保存整表覆盖写 DB + `store.reset()`；频控与静默时段用数字输入框；金额正则展示但不提供编辑框。

### 重要行为变化（勿回退）
- 状态回写真写库后，**跑一次 demo 学员数据就永久推进** → `cli.py demo()` 和
  `eval/run_eval.py replay()` 开头调 `db.reseed_students()` 回初始态保证可重复；
  app.py 的「一键演示」「重置学员数据」按钮同理（会覆盖工作台对学员的手工编辑）。
- 回归结果：cli 两遍输出一致；eval 30 条指标与 JSON 时代完全一致（28/30、26/27、1/19、0/11、0/9）。
- 卡片/禁语/学员档案改编辑入口已换；knowledge.json 仍需改文件后 reseed（嵌套结构暂不做编辑 UI）。
